# Bakery Stock Control

A small offline inventory app for tracking bakery ingredients, product recipes, and daily production.

## What it does

- Records raw materials with stock, minimum limits, and refill targets.
- Connects products to ingredient quantities through recipes.
- Checks available stock before production is recorded.
- Deducts ingredients automatically and keeps a recent production log.
- Shows low-stock items and refill amounts on the dashboard.

## Run it

Open `index.html` in a modern browser. No installation or server is needed. Use **Load Sample Data** to try the app with example records, or add your own materials, products, and recipes.

Data is saved in your browser's local storage. It stays on that browser and is not synced between devices. Clearing site data or using **Reset All Data** removes the saved records.

## Built with
